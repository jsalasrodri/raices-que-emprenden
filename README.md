# Raíces que Emprenden

Blog del Proyecto de Humanidades Digitales (Práctica en Responsabilidad Social, UNIMINUTO).

## Estructura
- `index.html`: portada del blog
- `entrada-1.html`: Entrada 1, contexto del proyecto
- `entrada-2.html`: Entrada 2, problemática, contexto, objetivos, justificación y referencias
- `assets/css/styles.css`: estilos (colores en `:root`)
- `assets/js/graficos.js`: datos de los gráficos (edita los arreglos `data`)
- `assets/js/mapa.js`: puntos del mapa (edita el arreglo `puntos`)
- `assets/img/`: ilustraciones
